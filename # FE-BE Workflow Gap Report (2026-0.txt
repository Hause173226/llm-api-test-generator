## 3) Ket luan tong quan

FE hien tai **chua noi chuan day du** voi workflow BE tra ve. Co nhieu phan da noi dung, nhung cac diem quan trong nhat cua luong generation callback (job polling), order gate validation, va spec parsing async van thieu/sai.

Danh gia nhanh:

- Muc do dong bo tong the: **Trung binh (partial alignment)**
- Rui ro cao nhat: **false-success generation**, **bo qua gate check chinh thuc**, **khong poll parse status cho upload async**

## 4) Diem dung/chuan da co

1. FE da goi dung endpoint generation canonical `POST /test-suites/{suiteId}/generate-tests`.
2. FE da dung endpoint run results `GET /test-suites/{suiteId}/test-runs/{runId}/results` va co handle state `resultsSource = unavailable`.
3. FE da tach GET explanation (cache-first) va POST explanation (generate live) trong Suggestions page.
4. FE da dung `rowVersion` trong update/delete environment va sanitize secret `******` truoc khi submit.
5. FE da co luong suite creation + selectedEndpointIds + order proposal + approve.

## 5) Cac diem THIEU / SAI / THUA (chi tiet)

## Critical

### C-01 [SAI + THIEU] Generation callback flow bi gia lap thanh cong, khong poll `generation-status`

- Chuan BE yeu cau:
  - Unified flow tra `202 Accepted` + `jobId`, FE phai poll `GET /generation-status` cho den khi job complete/failed.
  - Tham chieu: `FE_BE_AutoTest_LLM_Integration_Guide.json` (workflowAtoZ: poll generation-status, apiContracts.test order/generation).
- FE hien tai:
  - Goi `POST /test-suites/${suiteId}/generate-tests`, sau do cho timeout co dinh 2 giay va set status success.
  - Khong goi `GET /generation-status`.
  - Chung cu:
    - `src/pages/GeneratingTestCasesPage.tsx:92`
    - `src/pages/GeneratingTestCasesPage.tsx:105`
    - `src/pages/GeneratingTestCasesPage.tsx:107`
- Tac dong:
  - UI co the bao "Generation complete" khi backend job van dang `Queued/Triggering/WaitingForCallback`.
  - De redirect sang test cases som, gay nham lan "khong co case" hoac data chua dong bo.
- Khuyen nghi:
  - Bat buoc parse response `GenerateTestsAcceptedResponse` lay `jobId`.
  - Poll `GET /test-suites/{suiteId}/generation-status?jobId=...` theo interval + timeout + cancel.
  - Chi set success khi backend status `Completed`; set error neu `Failed` + show `errorMessage`.

### C-02 [SAI] Route wiring khong khop: path param `:suiteId` nhung page doc query param `suiteId`

- FE hien tai:
  - Route khai bao `/test-suites/:suiteId/generating`.
  - Page lai lay `suiteId` bang `useSearchParams().get("suiteId")`.
  - Chung cu:
    - `src/AppRouter.tsx:108`
    - `src/pages/GeneratingTestCasesPage.tsx:17`
    - `src/pages/GeneratingTestCasesPage.tsx:18`
- Tac dong:
  - Truy cap route dung path param se co kha nang bi "Missing required parameters" neu query khong co.
- Khuyen nghi:
  - Dung `useParams<{ suiteId: string }>()` trong `GeneratingTestCasesPage`.

### C-03 [THIEU] Khong poll `parseStatus` cho upload mode parse async

- Chuan BE yeu cau:
  - OpenAPI YAML/Postman co the tao spec `Pending`; FE phai theo doi `parseStatus` truoc khi di tiep.
- FE hien tai:
  - Upload xong thi cho 1.5s roi navigate sang Endpoints, khong poll parse status.
  - Hook specifications chi fetch 1 lan, khong co poll loop.
  - Chung cu:
    - `src/pages/SpecificationPage.tsx:127`
    - `src/pages/SpecificationPage.tsx:132`
    - `src/pages/SpecificationPage.tsx:134`
    - `src/hooks/useSpecifications.ts:15`
    - `src/hooks/useSpecifications.ts:69`
- Tac dong:
  - User vao endpoint/suite khi spec chua parse xong -> danh sach endpoint thieu/rong, workflow tiep theo de loi.
- Khuyen nghi:
  - Sau upload, neu `parseStatus` la `Pending`, poll chi tiet spec den khi `Success/Failed`.
